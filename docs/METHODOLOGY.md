# 方法与课程版本修订

本仓库是课程分析的个人作品集整理版。为避免保留未核验数字，所有公开结果从原始 CSV 重新计算。

| 原问题 | 整理版处理 |
|---|---|
| 部分频次用 `Event Name.count()`，遗漏无名称记录 | 所有记录频次统一用 `groupby.size()` |
| 先排除 2021 后重新读取，造成窗口变化 | 仅加载与筛选一次，统一 1970—2020 |
| 将国家级影响记录直接称为全球独立灾害 | 保留 ID，主要指标明确标记为国家级记录 |
| 死亡和受影响人数未知填零 | 保留缺失，分别报告字段覆盖率 |
| 缺少月份填 6 月，全球使用北半球四季 | 月份未知不填，使用日历月，不推断季节 |
| 月份/日期不全但报告精确持续时间 | 不输出持续时间指标 |
| 缺失指标数量不同的严重程度分数直接比较 | 不输出未经校准的综合评分 |
| 损失集中度被解释为全体灾害结论 | 分母限定为有损失数据的国家级记录 |
| 名义损失增长被归因为资产暴露或灾害强度 | 显示损失覆盖率，明确未经通胀及暴露调整，不作因果归因 |
| 大量重复报告、压缩包和成员分工信息 | 仅保留匿名代码、生成结果与说明文档 |

## 指标定义

- 记录数：窗口内国家级唯一影响记录的行数。
- 损失覆盖率：该分组中经济损失非空记录数 / 该分组全部记录数。
- 已记录损失总额：对已报告数值求和；全缺失组返回未知，不返回零。
- 集中度：将损失已知的记录按损失降序排列，找到累计损失首次达到 80% 的最小记录数，除以损失已知记录数。
- 记录数地图/排名不能替代风险率；缺少人口、面积和资产暴露分母。
- 当有损失记录包含真实零值时，该记录仍进入集中度分母；未知不进入分母。

## 尚未解决的证据边界

历史快照未和线上源逐条核验；灾害年度报告覆盖、历史分类变化、名义美元与资产暴露变化仍限制跨期比较。
本项目不提供预测、因果估计、投资结论或精算定价。
本次版本不沿用原始地图的错误计数，改为可离线打开的交互国家排名，保留地域比较及悬停详情。
