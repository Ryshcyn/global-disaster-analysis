# 分析方法

## 研究设计

本研究采用描述性统计，以国家级灾害影响记录为主要分析单位，统一选择 1970—2020 年。
问题涵盖时间分布、灾害类型、地域结构、损失集中度与数据覆盖。
年度和类别频次使用记录行数，不要求名称、死亡或损失字段非空。

## 数据处理

1. 检查必要列，去除文本首尾空格，将空字符串视为未知。
2. 显式解析年份、月份及主要影响字段；无法解析的非空数值触发错误。
3. 筛选研究年份，验证国家级编号非空、唯一且国家后缀与 ISO 一致。
4. 验证分组标识完整，拒绝负数或无穷大的影响值。
5. 月份仅接受 1—12 的整数；非法值转为未知并计数。
6. 提取事件编号及十年区间字段，用于核验粒度和时间汇总。

保留未知死亡、受影响人数和损失，按图表所需字段选择有效样本。
原始宽表在本地保留，分析使用与研究问题相关的字段，不为消除空值而删除全部不完整记录。

## 指标定义

| 指标 | 定义 |
|---|---|
| 记录数 | 窗口内国家级唯一影响记录的行数 |
| 事件编号数 | 去除国家后缀后的不同编号数，用于核验粒度 |
| 损失覆盖率 | 损失非空记录数 / 该组全部记录数 |
| 已报告总损失 | 对非空损失求和；全缺失组仍为未知 |
| 80% 损失集中度 | 降序累计达到 80% 损失的最小记录数 / 损失已知记录数 |
| 月份分布 | 按有效开始月份分组，不推断全球统一季节 |

集中度分母包含已记录的真实零值，排除未知值。金额使用名义美元，原始字段单位为千美元。
报告和图表显示十亿美元时，将原始数值除以一百万。

## 可复现性与质量控制

输入文件通过 SHA-256 标识。报告、表格、图表和 Notebook 使用同一分析函数及窗口。
计数在年份、类型、大洲交叉表及有效月份间对账。
回归测试覆盖无名称计数、全缺失组求和、未知与零值、重复编号、年份筛选及集中度边界。

## 解释范围

历史记录混合了灾害变化与报告覆盖变化；金额未经通胀、资产暴露和人口规模调整。
国家和大洲榜单是绝对记录规模，不是风险率。缺失机制未经识别，不能将已知金额样本视为全体的无偏样本。
本研究不进行因果识别、预测或精算定价。
