# 项目讲解与简历表述

## 一分钟讲解

这是从课程项目整理出的全球自然灾害探索性分析。我负责数据处理、统计分析、可视化和报告撰写。
核心问题是灾害记录如何分布、已报告经济损失是否集中，以及缺失数据会怎样影响结论。
整理时发现事件名称字段大量缺失，所以把按名称计数改为按国家级唯一记录计数；同时保留未知影响值，
避免把缺失视为零，并统一分析年份。结果通过代码、Notebook、汇总表和图表相互核对。
我最关注的是结论适用范围：损失集中度描述的是有损失记录的样本，不能直接外推至所有灾害。

## 简历可用描述

**全球自然灾害记录与经济损失分析｜课程项目，独立完成**

- 使用 Python、Pandas 对约 1.46 万条灾害原始记录进行字段核验、缺失分析和类别标准化，保留国家级影响记录编号，统一分析窗口与计数口径。
- 围绕时间、地域、灾害类型及损失集中度开展探索性分析，制作静态分析图与离线交互式国家排名，输出可复现代码、Notebook 和分析报告。
- 识别名称缺失造成的计数偏差及零值填补对结论的影响，以损失覆盖率和明确样本分母约束趋势与集中度解读。

不要把课程数据描述为自行采集的实时数据，也不要把描述性结果称为预测或因果发现。

## 面试追问

1. 为什么 `count()` 与 `size()` 的结果不同？名称缺失与分组键缺失分别如何处理？
2. 为什么缺失死亡人数不能直接视为零？怎样保留未知并报告覆盖率？
3. 同一事件影响多个国家时，记录数与独立事件数有什么差别？
4. 为什么不能仅从名义美元曲线判断灾害变得更严重？
5. 损失集中度的分母是什么？若缺失不是随机的，结论会怎样受到限制？
6. 如何把这套分析方法迁移到业务数据？可讨论长尾损失、重点样本、数据完整性和指标口径，但不要宣称本项目已验证商业收益。
